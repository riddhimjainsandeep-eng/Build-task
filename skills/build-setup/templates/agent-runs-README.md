# Run log

One line per finished run, newest last. Written by Phase 5.

Format: `- YYYY-MM-DD — <task> — <outcome>. <one sentence of plain English>`

The folders beside this one:

- **`upcoming/`** — tasks written but not started. A prompt file lives here until
  work begins on it.
- **`active/`** — the task being worked on right now. One folder per task, named
  `YYYY-MM-DD_task-name`, holding that run's phase files.
- **`done/`** — finished runs, each with its archive zip. **Do not read these
  unless explicitly asked** — they are history, and reading them costs context
  for no benefit.

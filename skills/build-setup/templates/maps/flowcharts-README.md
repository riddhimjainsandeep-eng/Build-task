# Flowcharts

Plain-language diagrams, **written for the owner to read**, not for a developer.
One per file, numbered so they read straight through. Diagrams that live inside
the technical maps stay where they are — this folder is only for the ones meant
to be understood without knowing the code.

## The rules

- **Plain everyday language.** No function names, no file paths, no jargon. If a
  box needs a technical term to make sense, the diagram is at the wrong level.
- **Short boxes.** A few words each. If a box needs a sentence, split it.
- **No crossing arrows.** If arrows must cross, the layout is wrong — rearrange
  until they do not.
- **Mermaid**, so it renders anywhere.
- One diagram per file. A file that needs two diagrams is two files.

## Adding one

A task that produces a chart, or invalidates an existing one, puts it here with
the next number and adds its line to the index below. Phase 5 does this.
